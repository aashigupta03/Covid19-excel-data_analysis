# COVID-19 Global Data Analysis Dashboard (Excel Project)

## Project Overview
This project analyzes global COVID-19 data using Microsoft Excel.  
The dashboard provides insights into confirmed cases, deaths, recovery rates, active cases, and regional analysis.

## Tools & Features Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- XLOOKUP
- VLOOKUP
- INDEX MATCH
- Conditional Formatting
- Interactive Dashboard
- Slicers
- KPI Cards

## Key Analysis Performed
- Total Global Cases Analysis
- Country-wise Death Rate Analysis
- Recovery Rate Analysis
- Region-wise Comparison
- Weekly Growth Analysis
- Top 10 Countries by Cases

## Dashboard Features
- Interactive slicers
- Dynamic charts
- Country search using XLOOKUP
- Combo charts with secondary axis
- KPI summary cards

## Key Insights
- Top countries contribute majority of global cases
- Recovery rate varies significantly across regions
- Some countries show rapid weekly growth trends
